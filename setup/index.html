Team setup

This page makes the config.json settings file that Piper Robotics Live (and later the scouting app) reads. Change anything below, tap Download config.json, then upload that file to the top folder of your GitHub repository, replacing the old one. Phones pick up the change the next time the app opens.

Everything here is public: anyone who opens your site can read this file. Only put in keys that are meant for websites (a Blue Alliance read key, a YouTube key locked to your site). Never put your FIRST API key or your scouting app's team key here.
